# Reports folder

Put annual reports and financial releases here as PDF, named `COMPANY_YEAR_description.pdf`, for example:

```
Mutandis_2025_communique.pdf
Mutandis_2024_rapport_annuel.pdf
```

Where to find them:
- Company websites, Investors section (for example mutandis.com)
- AMMC, the Moroccan capital markets authority: ammc.ma
- Casablanca Stock Exchange: casablanca-bourse.com

The PDFs themselves are not committed to this repository. Each user downloads them from the official sources.
